## [v4.2.0] - 2026-08-17 :: Edición Producción Enterprise

### 🎬 Novedades Destacadas
- **Tráiler Cinematográfico AAA (16s)**: Secuencia de apertura en 4 bloques cronometrados con renderizado Canvas 2D/WebGL a 60 FPS, niebla mística de Real del Monte, topografía de Hidalgo en filamentos dorados, subgrave Web Audio a 60 Hz, locución sincrónica de 17 palabras (~3.4 palabras/segundo) y despliegue del Medallón del Colibrí Mecánico.
- **Transición Active Smooth-Motion**: Desplazamiento fluido (*smooth-motion bezier*) del medallón hacia el header en la esquina superior izquierda.
- **Cuadrante Cockpit Balanceado**: Integración de `<CrownGovernanceCard />` en el tablero de arquitectura `Cockpit.tsx` completando el grid de 4 columnas con telemetría Zero-Trust y monitoreo de veto ARGUS.

### 🛡️ Gobernanza & API
- API canónica versionada `/api/v1/isabella` con soporte para auditoría, memoria jerárquica, catálogo de herramientas y sandbox.
- Motor Soberano Local resiliente para operación 100% *Air-Gapped* cuando no se dispone de credenciales cloud.
- Saneamiento del nombre de directorio para ejecución nativa transparente en Windows CLI.
