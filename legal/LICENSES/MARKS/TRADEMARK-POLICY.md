## 1. Titularidad
La marca, logotipos y denominación "Isabella" pertenecen a los titulares del
proyecto Isabella. No se transmiten bajo las licencias de código ni de
documentación (licenciamiento cuádruple).

## 2. Uso permitido
- **Referencia nominativa:** mencionar "Isabella" para identificar el software
  o indicar compatibilidad, siempre que no se implique patrocinio/afiliación
  del titular, y conforme a prácticas de uso justo de marcas.
- **Atribución:** usar el nombre con un aviso de titularidad.

## 3. Uso restringido
- No registrar ni usar nombres/dominios confusamente similares.
- No usar las marcas para derivar beneficio en productos ajenos sin autorización.
- No usar las marcas de forma que sugieran certificación o respaldo.

## 4. Uso comercial
El uso de las marcas en ámbito comercial requiere autorización previa por
escrito (ver `COMMERCIAL-LICENSE.md`).
