# Legal & Licensing

Isabella se publica bajo un **licenciamiento cuádruple** en directorios
separados, para cubrir código, contenido, documentación y marcas, y para
separar el uso de código abierto del comercial.

## Licencias cuádruples

| Carpeta | Cobertura | Licencia |
|---------|-----------|----------|
| `LICENSES/CODE/` | Código fuente | Apache License 2.0 |
| `LICENSES/COMMERCIAL/` | Uso comercial del software | Commercial License |
| `LICENSES/CONTENT/` | Activaciones / contenido (incl. sonidos de Isabella) | CC BY-NC-ND / activación |
| `LICENSES/DOCS/` | Documentación y docs del marco | CC BY 4.0 |

> Nota: la licencia Apache **no** otorga derechos de marca. La marca "Isabella"
> se gestiona en `LICENSES/MARKS/` y en `LICENSES/COMMERCIAL/TRADEMARK-POLICY.md`.
> El uso comercial requiere la Commercial License.

## Cómo elegir

- **Open source** (no comercial): código bajo Apache 2.0.
- **Comercial**: software propietario → `COMMERCIAL-LICENSE.md`.
- **Contenido/activos**: `CONTENT-LICENSE.md`.
- **Documentación**: `DOCS-LICENSE.md`.
